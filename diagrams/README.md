# Diagrams

This directory contains simplified portfolio reconstructions of the project's network design visuals.

## Available diagrams

- [Logical Network](logical-network.md) — high-level traffic and infrastructure relationships
- [Physical Network](physical-network.md) — proposed equipment and workplace placement

## Design rule

These diagrams are derived from the project documentation but are **not** presented as the original drawings or as production configurations. They intentionally omit unsupported implementation details such as IP addressing, VLAN IDs, routing protocols, firewall rules, access-point models, port assignments, and configuration values.

Where the source documents contain an inconsistency, the portfolio documentation records it rather than silently inventing a resolution. See [Source Validation Notes](../documentation/source-validation.md).
