# Diagrams

This directory is reserved for portfolio-safe diagrams extracted or recreated from the project deliverables.

Recommended diagram set:

1. Logical network design
2. Revised logical network design
3. Physical network design
4. Revised physical network design

Diagrams should be exported at readable resolution and should not contain private client contact information. Keep labels faithful to the project documentation; do not add technologies or architecture components that were not part of the project.
