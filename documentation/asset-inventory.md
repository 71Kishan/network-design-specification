## Selection Rationale

The physical design selected the lower-cost options documented in the project for the proposed implementation plan: MNSi for Business connectivity, HP Elite Dragonfly notebooks, the 7k BTU air-conditioned server rack, and Altamae adjustable-height desks.

The project did not propose replacing all existing infrastructure. Selected network, power, display, peripheral, printing, and cabling assets were planned for reuse.

## Source-Data Note

Some earlier sections of the original presentation reference a Cisco Catalyst 9300 in the existing server-rack discussion, while the physical asset list specifies **two Cisco Catalyst 9200L 48-port PoE switches** for reuse. This inventory follows the physical asset list because it is the project's explicit asset-register section. The discrepancy is preserved rather than silently corrected.

## Project Status

This is a **proposed asset plan**, not an installed inventory. The student team did not perform the physical deployment documented in the implementation plan.
