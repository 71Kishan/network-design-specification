# Physical Infrastructure Design

## Asset Planning

The physical design translated the logical recommendations into a proposed equipment and workplace layout.

### Proposed additions

| Item | Quantity | Planned location |
|---|---:|---|
| Business Internet/router solution | 1 | Hallway / network entry point |
| HP Elite Dragonfly workstations | 70 | Plant-wide |
| 7k BTU air-conditioned server rack | 1 | Server room |
| Altamae 48-inch adjustable standing desk | 50 | Plant-wide |

### Existing equipment proposed for reuse

The physical design identified selected existing equipment for reuse, including:

- Cisco Catalyst 9200L 48-port PoE switches
- Cisco ASA 5516-X firewall
- UPS / 715W power equipment
- Dell monitors
- Logitech keyboards and mice
- Existing office printers
- Existing label printers
- Existing Cat5e and fiber cabling where appropriate

### Equipment to be removed

The existing Dell Inspiron 5000 endpoint fleet was identified for removal/lease return as part of the workstation refresh.

## Physical Layout Considerations

The design considered:

- Server-room rack placement and cooling
- Network equipment placement
- Cabling requirements
- Wireless coverage
- Workstation deployment
- Desk placement and ergonomics

## Why the Physical Design Matters

A logical network diagram alone does not capture the operational requirements of an infrastructure deployment. The physical design connects the network architecture to equipment locations, cabling, rack capacity, cooling, endpoint placement, and workplace constraints.

## Scope Boundary

The physical design represents the team's proposed implementation plan. The project team did not carry out the production installation.
