# Requirements Analysis

## Data Collection

The project began with requirements gathering through an on-site walkthrough and a user survey. The survey covered personal-computer usage, ergonomics, network performance, and security.

The goal was to identify practical issues affecting users and infrastructure before designing the proposed solution.

## Existing Environment Highlights

The documented environment included:

- Approximately 70 employee laptops/workstations
- Office and label printers
- Cisco network and security equipment
- A server-room/rack environment
- Microsoft Windows endpoints
- Microsoft 365 usage
- Epicor usage
- Cloud-based services and storage
- Backup services for Microsoft 365 and Active Directory

The project documentation also referenced a 50 Mbps symmetrical fiber connection and a Cisco ASA 5516-X firewall.

## Requirements Identified

### Network and Internet

The design identified a need for greater Internet/network capacity to reduce delays during periods of high activity and large cloud-file transfers.

### Endpoints

Workstation performance was identified as an area for improvement. The project documented slow login/readiness behavior and limited RAM on the existing endpoint configuration.

### Server Room

The rack environment required additional capacity and improved cooling to better support the infrastructure.

### Ergonomics

The existing workstations provided limited desk-height adjustment. Adjustable sit/stand desks were therefore included in the proposed physical design.

## Requirement-to-Design Traceability

| Requirement | Observed Concern | Proposed Direction |
|---|---|---|
| Network capacity | Delays during high activity and large cloud transfers | Higher-speed business Internet |
| Endpoint performance | Slow login/readiness and limited RAM | Modern business-class workstations |
| Rack environment | Limited size/cooling | Larger air-conditioned rack |
| Ergonomics | Limited desk adjustability | Adjustable sit/stand desks |

## Design Principle

The project treated requirements gathering as the starting point for the design. Proposed equipment was selected to address documented operational concerns rather than simply modernize the environment without a defined requirement.
